CYD D&D — Бестиарий и трекер заклинаний

Прошивка для платы CYD ESP32-2432S028. Работает прямо из браузера (Chrome или Edge на компьютере) через Web Serial — ничего устанавливать не нужно.

  1. Подключите плату к компьютеру по USB (micro-USB или USB-C — любой из двух портов на плате).
  2. Нажмите кнопку ниже и выберите появившийся COM-порт платы.
  3. Дождитесь окончания прошивки (обычно 30–60 секунд).
  4. Не забудьте отдельно скопировать игровые данные на microSD карту — см. раздел «Данные на microSD» в README репозитория.
Ваш браузер не поддерживает Web Serial API. Откройте эту страницу в Chrome или Edge на компьютере (мобильные браузеры не подходят). Страница должна быть открыта по HTTPS — обычно так и есть на GitHub Pages, попробуйте обновить страницу.

Прошивка собирается автоматически из исходников репозитория через GitHub Actions при каждом обновлении кода — эта страница всегда указывает на последнюю собранную версию.
