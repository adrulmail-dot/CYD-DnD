# CYD D&D — Бестиарий и Трекер заклинаний

**Версия: 0.01 beta** — проект находится на раннем этапе, часть параметров
(калибровка тача, ориентация экрана под конкретный экземпляр платы)
донастраивается по мере тестирования на реальном железе.

Приложение для платы **CYD ESP32-2432S028** ("Cheap Yellow Display", 2.8" ILI9341
320×240 + резистивный тач, вариант с двумя USB-разъёмами) — офлайн бестиарий
D&D 5e с подсказками по тактике боя, лист персонажа с полным набором
параметров, инвентарь и трекер заклинаний. Все данные хранятся на microSD
и загружаются устройством на лету — прошивка не хранит игровые данные в
самой flash-памяти (её слишком мало).

## Важно про источник данных и лицензии

Официальные книги D&D (Monster Manual и его иллюстрации) защищены авторским
правом Wizards of the Coast/Hasbro — встраивать их текст и картинки в
раздаваемое приложение нельзя. Поэтому:

- **Статблоки монстров, заклинания и снаряжение** взяты из **5e SRD 5.1**
  (System Reference Document) — открытого игрового контента, распространяемого
  по Open Gaming License. Это официальный, юридически открытый поднабор
  правил D&D 5e (322 существа, 319 заклинаний, оружие/броня/237 магических
  предметов). Данные извлечены из открытого проекта
  [open5e/open5e-api](https://github.com/open5e/open5e-api) (`data/v1/wotc-srd`).
- **Иллюстрации**: у 12 существ (абилет, анкег, бехир, василиск, було, тёмный
  плащ, хизроу, коутль, петушок-васелиск, мантия тьмы, ржавое чудище,
  тёмный охотник) есть готовые картинки — они взяты из того же проекта
  open5e и распространяются по лицензии **CC BY-NC 4.0** (некоммерческое
  использование с атрибуцией). Атрибуция и текст лицензии лежат в
  `sd_card_data/img/LICENSE.txt`. Для оставшихся ~310 существ, у которых
  собственной легальной иллюстрации нет, интерфейс рисует иконку-заглушку
  (цветной кружок с первой буквой имени) — это исключает риск нарушения
  авторских прав.
- **Подсказки «как победить»** (вкладка «Тактика» в бестиарии) — полностью
  оригинальный текст, сгенерированный алгоритмически на основе открытых
  числовых полей статблока (уязвимости/сопротивления/иммунитеты, самый
  слабый спасбросок, наличие легендарного сопротивления, тактики стаи,
  регенерации, полёта и т.д.) — см. `tools/build_data.py`, функция `gen_tips`.
  Это не пересказ и не цитата какого-либо издания.

Если понадобится **обновить или расширить датасет**, запустите ещё раз
`python3 tools/build_data.py /путь/к/клону/open5e-api` (см. ниже).

## Возможности

- **Бестиарий**: поиск по имени, фильтр по типу существа, полный статблок
  (характеристики, КД, ХП, скорость, спасброски, навыки, сопротивления/
  иммунитеты/уязвимости, особенности/действия/легендарные действия) и
  вкладка с тактическими подсказками.
- **Персонаж**: имя/раса/класс/предыстория/мировоззрение/уровень, все 6
  характеристик, боевые параметры (ХП/temp HP/AC/скорость/инициатива/
  бонус мастерства/кости хитов), владение спасбросками и всеми 18 навыками
  (+ экспертиза), валюта (медь/серебро/электрум/золото/платина), заметки,
  черты характера, умения.
- **Инвентарь**: добавление своих предметов или из каталога SRD (оружие/
  броня/магические предметы), учёт веса и переносимого груза (Сила × 15
  фунтов), отметка «экипировано».
- **Заклинания**: ячейки заклинаний по уровням 1–9 (использовать/
  восстановить/настроить количество), долгий отдых, список известных/
  подготовленных заклинаний, поиск и просмотр по каталогу SRD (319 штук)
  с полным описанием и добавлением одним нажатием.
- Всё сохраняется на microSD (`/save/character.json`) и переживает
  перезагрузку.

## Железо

| Функция          | GPIO (см. `include/pins.h`) |
|------------------|------------------------------|
| TFT MISO/MOSI/SCLK/CS/DC | 12 / 13 / 14 / 15 / 2 |
| TFT подсветка    | 21 |
| Тач CS (XPT2046) | 33 (использует ту же шину SPI, что и TFT) |
| microSD CS/MOSI/MISO/SCK | 5 / 23 / 19 / 18 (отдельная шина HSPI) |
| RGB светодиод    | 4 / 16 / 17 |
| Динамик          | 26 |
| Фоторезистор     | 34 |

Этот пинаут — стандартный для плат серии ESP32-2432S028 (в том числе
ревизий с двумя USB-разъёмами — micro-USB и USB-C, они отличаются только
разъёмом, GPIO не меняются).

**Если у вас ESP32-S3 версия платы или ёмкостный тач (CST820/GT911 по I2C)**
вместо резистивного XPT2046 — поменяйте `board = esp32dev` в
`platformio.ini` на `esp32-s3-devkitc-1` и потребуется отдельный I2C-драйвер
тача вместо `tft.getTouch()` (в текущей прошивке используется резистивный
XPT2046 через встроенную поддержку TFT_eSPI).

## Прошивка без ручной сборки (рекомендуется)

В репозитории настроен GitHub Actions (`.github/workflows/build-firmware.yml`),
который **сам собирает прошивку в облаке** при каждом push и публикует
браузерный установщик на базе [ESP Web Tools](https://esphome.github.io/esp-web-tools/):

1. Один раз включите GitHub Pages для репозитория: **Settings → Pages →
   Source: Deploy from a branch → ветка `gh-pages`, папка `/(root)`**
   (ветка `gh-pages` появится сама после первого прогона workflow).
2. Дождитесь зелёной галочки во вкладке **Actions**.
3. Откройте опубликованный адрес страницы (Settings → Pages покажет ссылку,
   обычно вида `https://<ваш-логин>.github.io/CYD-DnD/`) в **Chrome или
   Edge на компьютере**.
4. Подключите плату по USB, нажмите «Установить прошивку», выберите
   COM-порт — готово, никаких команд вводить не нужно.

Страница всегда указывает на самую свежую версию, собранную из текущего
кода репозитория. Копию скомпилированных `.bin`-файлов также можно скачать
без браузерного флешера — во вкладке **Actions → (последний прогон) →
Artifacts**.

## Ручная сборка и прошивка

Если предпочитаете CLI или хотите править код локально — тоже есть
однокомандный вариант:

```bash
bash tools/flash.sh     # macOS/Linux: поставит PlatformIO при необходимости и прошьёт
tools\flash.bat          # Windows: то же самое, можно просто запустить двойным кликом
```

Либо вручную через [PlatformIO](https://platformio.org/):

```bash
pio run                       # собрать
pio run -t upload             # прошить (подключите плату по USB)
pio device monitor -b 115200  # серийный монитор для отладки
```

Зависимости (подтягиваются автоматически через `lib_deps` в
`platformio.ini`): TFT_eSPI, LVGL 8.3, ArduinoJson 6, TJpg_Decoder.

> Прошивка написана и вручную сверена с исходниками TFT_eSPI, LVGL 8.3 и
> TJpg_Decoder (сигнатуры функций, структура `lv_img_dsc_t` и т.д.), но
> в песочнице, где готовился этот код, не было доступа к реестру пакетов
> PlatformIO и к тулчейну Xtensa, поэтому реальная сборка там не
> прогонялась. GitHub Actions (см. выше) собирает её на обычном
> GitHub-раннере с полным доступом в интернет — зелёная галочка во
> вкладке Actions и есть настоящее подтверждение, что код компилируется.
> Если сборка там всё же красная — откройте лог шага `Build firmware` и
> пришлите ошибку, структура кода модульная, правки будут точечными.

### Калибровка тача

В `src/main.cpp` зашиты типовые калибровочные значения резистивного тача
для CYD (`{200, 3700, 200, 3700, 7}`). Если координаты нажатия ощутимо
"плывут", прогоните штатный калибровочный скетч TFT_eSPI
(`Examples/Generic/Touch_calibrate`) и подставьте свои 5 чисел.

## Данные на microSD

1. Отформатируйте microSD в FAT32.
2. Скопируйте **содержимое** папки `sd_card_data/` в **корень** карты
   (то есть на карте должны появиться `bestiary_index.jsonl`,
   `spells_index.jsonl`, папки `bestiary/`, `spells/`, `items/`, `img/`).
3. Вставьте карту в слот на плате и включите устройство.

Если карта не найдена или на ней нет данных, на экране появится
соответствующее сообщение вместо краша.

### Пересборка датасета из исходников

```bash
git clone --depth 1 https://github.com/open5e/open5e-api
python3 tools/build_data.py open5e-api
```

Скрипт перечитывает `data/v1/wotc-srd/{Monster,Spell,Weapon,Armor,MagicItem}.json`
из клона open5e-api, ужимает поля под экономный формат для
ArduinoJson/микроконтроллера, генерирует тактические подсказки и
перекодирует иллюстрации в JPEG шириной 220 px. Результат — папка
`sd_card_data/`, которую нужно скопировать на карту (см. выше).

## Структура репозитория

```
platformio.ini        конфигурация сборки
include/               User_Setup.h (TFT_eSPI), lv_conf.h, pins.h
src/
  main.cpp             инициализация экрана/тача/SD, цикл LVGL
  app_state.*           единое глобальное состояние приложения
  model/                Character, Inventory, Spellbook (чистые данные)
  data/                 чтение бестиария/заклинаний/предметов и save-файла с SD
  ui/                    экраны LVGL (главный, бестиарий, персонаж,
                         инвентарь, заклинания) и переиспользуемые виджеты
tools/build_data.py     конвертер open5e SRD JSON → sd_card_data/
sd_card_data/           готовый датасет для копирования на microSD
```

## Известные ограничения / что доделать при первом запуске на плате

- Реальная компиляция на Xtensa-тулчейне не проверялась (см. выше) —
  возможны мелкие правки под конкретную версию библиотек.
- Байтовый порядок RGB565 у декодированных JPEG (`src/ui/img_loader.cpp`)
  подобран по документации TJpg_Decoder/TFT_eSPI, но цвета на 12 картинках
  с иллюстрациями стоит визуально проверить на первом прошитом устройстве —
  если они инвертированы/перепутаны местами R и B, поменяйте
  `TJpgDec.setSwapBytes(false)` на `true` в `load_jpeg_from_sd()`.
- Калибровка тача — см. раздел выше.
- Экран "Дом" показывает имя/уровень персонажа на момент запуска
  приложения (кэшируется один раз); если поменять имя на экране
  «Персонаж», на «Доме» оно обновится только после перезапуска.
